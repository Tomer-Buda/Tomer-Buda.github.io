# Assets Folder

Drop your resume PDF right here with the filename:

`Tomer_Buda_Resume.pdf`

Once placed at `assets/Tomer_Buda_Resume.pdf`, every **Resume** button on the website will automatically detect it and open/download your PDF directly (instead of showing the built-in resume summary modal).

You can also place any custom project screenshots here and reference them from `data/projects.js` using relative paths like `"assets/my-screenshot.png"`.
